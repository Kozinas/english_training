# English Training

Требования к расширению курса: [docs/REQUIREMENTS.md](docs/REQUIREMENTS.md). Переработка началась; полный курс по новым критериям **ещё не готов**. Фактическое состояние — в [журнале реализации](docs/IMPLEMENTATION.md).

Темп выбирает ученик. 30 минут — личное предпочтение для одного занятия, не сокращённая версия курса. Общий объём материала, практики и повторений сохраняется при любом темпе; меняется срок прохождения.

Темы и подтемы имеют естественный, разный объём и не привязываются к фиксированному времени или числу занятий. Их границы определяются содержанием; ученик может остановиться в середине работы и продолжить позже. Фиксированные циклы из пяти занятий убраны из данных, планировщика и интерфейса.

Личный курс для русскоязычного разработчика. Исходный ориентир — **30 минут, 5 дней в неделю**, без требования закончить страницу или подтему за один подход. Главный принцип — регулярная содержательная работа; после пропуска продолжайте с сохранённого места.

В [карте курса](course/INDEX.md) 40 топиков Pre-A1–C2, включая 6 технических. Сейчас расширен **P01**: четыре последовательные подтемы, подробные механизмы, 51 разобранный пример, **197 тренировочных заданий** и **96 заданий в восьми вариантах итоговых тестов**. В каждом новом разделе практики 10–20 заданий; есть отдельное смешанное повторение. Остальные 39 топиков пока содержат краткую первую версию и явно так отмечены, а не объявлены полными.

Доступны [справочные приложения](course/appendices/INDEX.md): 26 букв, 44 фонемы выбранной традиционной UK-модели, 12 временных/аспектуальных форм, 204 позиции неправильных глаголов и 36 производных. Область охвата, варианты и ограничения оговорены. Карточек **304**: сохранены прежние 240 ID, добавлены 64 слова/выражения, у всех есть UK IPA. Карточка переворачивается целиком; озвучивание и оценка вынесены наружу.

После каждой новой подтемы — обязательный отдельный тест. Ответом может быть слово, предложение или связный текст; устная часть требует реальной речи. Закрытые ответы проверяются автоматически, открытые остаются «ожидает проверки». После разбора можно записать внешнюю оценку с именем проверяющего, основанием и подтверждением прослушанного аудио для устной задачи. Отдельно видны успешные цели и пробелы; история попыток не стирается.

## Быстрый старт

Нужен Node.js 22 или новее. Устанавливать npm-пакеты не требуется.

```powershell
npm start
```

Откройте **http://127.0.0.1:4173**. Сервер привязан к вашему компьютеру. Для остановки — `Ctrl+C`. Если PowerShell блокирует `npm.ps1`, используйте `npm.cmd start` или `node scripts/serve.mjs`.

1. Откройте «Определить уровень». 48 заданий можно пройти за несколько занятий; черновик сохраняется.
2. Выполните письменную и устную части. Устная речь требует разговора и аудио для оценки произношения.
3. Экспортируйте JSON в `learner/private/progress.json` и попросите агента провести разбор по [рубрике](assessment/RUBRICS.md).
4. Внесите подтверждённые обсуждением оценки в профиль или попросите агента составить `learner/private/plan.md`.
5. Занимайтесь по маршруту, повторяйте слова, пересматривайте план раз в две недели.

До теста уровень **неизвестен**. Автоматический маршрут предварительный: он использует грамматику, чтение, доступное аудирование и внесённые ручные оценки. Общий CEFR приложение не сертифицирует. Ключи находятся в исходниках — это инструмент самообучения, не защищённый экзамен.

## Занятия с агентом без браузера

Откройте проект и напишите:

> Прочитай AGENTS.md. Проведи входную диагностику по одному заданию, не раскрывая ключи заранее. Учитывай разработку ПО и 30 минут пять дней в неделю. После проверки письма и речи составь мой план на четыре недели.

Для следующего занятия:

> Прочитай мой профиль и план из learner/private/. Продолжим с сохранённого места. Сегодня ориентир — 30 минут, но тему не сокращай и не закрывай по времени. Сохрани незавершённое, ошибки и следующие повторения.

Все модули доступны в [оглавлении курса](course/INDEX.md). [AGENTS.md](AGENTS.md) объясняет механику репозитория, диагностику, обратную связь, приватность и обновление прогресса. [План создания](docs/BUILD_PLAN.md) фиксирует архитектуру.

## Интернет, звук и данные

- Учебные тексты, тест, план и карточки работают локально при запущенном сервере, без интернет-соединения. Это не PWA: сам сервер должен работать.
- Распознавание использует **Web Speech API**, без скачивания модели и без API-ключа. Для этого режима нужен **интернет**, совместимый браузер и разрешение микрофона. Аудио может отправляться службе браузера. Поддержка API не гарантирует доступность службы. Подробнее: [MDN](https://developer.mozilla.org/en-US/docs/Web/API/SpeechRecognition).
- Озвучивание использует системные/браузерные английские голоса. Офлайн-работа зависит от установленного голоса; если голоса нет, интерфейс сообщает об этом. Для C1/C2 добавляйте живое аудио с разными голосами.
- Сходство транскрипта с фразой — сравнение слов, **не оценка произношения**. Аудио приложение не записывает в файлы. Для фонетического разбора нужен слушатель, слышащий запись.
- Прогресс и черновики хранятся в `localStorage` конкретного браузера и адреса. Смена порта/браузера или очистка данных не переносит прогресс. Регулярно экспортируйте JSON. Агент не видит эти данные до экспорта.
- Экспорт имеет `schemaVersion: 2`. Версия 1 импортируется с сохранением прежних карточек, ответов диагностики, черновиков и самопроверок. Старый чекбокс не засчитывает новое расширенное содержание. Сохраняются раздел подтемы, прокрутка, активное поле, все ответы и незаконченный итоговый тест. Ограничение хранилища зависит от браузера; при ошибке сохранения экспортируйте состояние из памяти.
- Личные данные и купленные книги исключены из Git. Сервер раздаёт только явно разрешённые публичные файлы; `learner/private/`, `library/private/` и `.git` через него недоступны.

## Структура

```text
AGENTS.md              правила агента и преподавателя
data/                  авторское содержание и входной тест
course/modules/        оглавления топиков / краткие материалы первой версии
course/subtopics/      наполненные подтемы, практика и итоговые тесты
course/appendices/     полные таблицы для явно указанного охвата
course/                методика, времена, звуки, словарь, контроль
assessment/            процедура диагностики и рубрики
library/open/          открытые PDF
library/private/       личные книги (ignored)
learner/templates/     пустые шаблоны профиля, плана, журнала
learner/private/       реальные ответы и планы (ignored)
web/                   интерфейс и логика обучения
scripts/               локальный сервер, сборка, проверка, загрузка
test/                  проверки логики и сервера
```

## Проверка и развитие

```powershell
npm run build   # пересобрать Markdown из data/*.mjs
npm run check   # проверить курс, ключи, зависимости и PDF
npm test        # проверить оценивание, план, импорт, SRS и сервер
npm run books  # получить/проверить открытые PDF, нужен Python 3.10+
```

Полный протокол: [docs/TESTING.md](docs/TESTING.md). Для изменения содержания редактируйте `data/*.mjs`, затем выполните build/check/test. Не меняйте ID без миграции пользовательского прогресса. Сохранённые планы и результаты не следует публиковать в открытом репозитории.

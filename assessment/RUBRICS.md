# Ручная оценка продуктивных навыков

Оценивайте задание и уровень его сложности отдельно. Балл 3/4 на простом представлении не равен C1. Ни одна таблица баллов здесь не является валидированной конверсией в CEFR. Используйте [официальные описания CEFR](https://www.coe.int/en/web/common-european-framework-reference-languages/cefr-descriptors) как ориентир наблюдаемых возможностей.

## Аналитическая шкала 0–4

| Балл | Наблюдаемое выполнение |
|---|---|
| 0 | Задание выполнено в недостаточном для понимания объёме; данных всё же достаточно для оценки этого задания |
| 1 | Основной смысл приходится восстанавливать; требуется постоянная поддержка |
| 2 | Основная задача выполнена, заметны ограничения и неоднократная помощь |
| 3 | Задача выполнена самостоятельно, понятно, с локальными исправлениями |
| 4 | Уверенное, гибкое и точное выполнение с адаптацией к изменению условий |

**Unknown — не 0.** Нет образца/аудио или задача не позволяет наблюдать навык → unknown. Запишите это явно.

Письмо: выполнение задачи; организация/связность; точность конструкций; лексика/сочетаемость; уместность регистра. Для каждой шкалы — балл, одна цитата, объяснение и следующее упражнение. Не усредняйте до CEFR без сопоставления с требованием задания.

Речь: выполнение задачи; понятность структуры; грамматика/лексика; плавность и самокоррекция; взаимодействие (реакция на вопросы, уточнение, очередность). Плавность оценивается по аудио, взаимодействие — по реальному обмену, не монологу.

Произношение: понятность для слушателя; различение значимых звуков; словесное ударение; ритм и смысловые группы; интонация/выделение контраста. Допустимы нормативные UK/US и другие понятные варианты. Не штрафуйте за наличие акцента как такового. ASR confidence/процент совпадения не заменяют эти критерии.

## Задания для уточнения уровня

| Ориентир | Что проверить на новом материале |
|---|---|
| Pre-A1 | Имя, числа, узнаваемые слова; помощь и повторение допустимы |
| A1 | Простое представление, знакомые предметы, короткие вопросы |
| A2 | Бытовая задача, описание события, простая договорённость |
| B1 | Связный рассказ, причина решения, знакомая рабочая проблема |
| B2 | Аргументированный выбор, спонтанные уточнения, преимущества и ограничения |
| C1 | Сложные источники, точная оговорка, гибкое изменение регистра |
| C2 | Тонкие смысловые различия, синтез сложных позиций, длительная неподготовленная дискуссия |

Это авторские учебные ориентиры, не буквальные официальные дескрипторы. Подтверждайте устойчивость на нескольких задачах и в разные дни. Грамматическая сложность сама по себе не определяет уровень.

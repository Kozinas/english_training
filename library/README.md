# Учебная библиотека

Две открытые книги хранятся в `open/`; точные файлы, размеры, даты и SHA-256 — в [DOWNLOADS.json](DOWNLOADS.json). В [SOURCES.json](SOURCES.json) указаны авторы, издатели, ссылки, лицензии и исключения. `npm run books` скачивает исходные PDF издателей, проверяет сигнатуру и не заменяет существующий файл без проверки его происхождения. Интернет нужен для первоначального получения; затем PDF читаются офлайн.

| Книга | Для чего | Права |
|---|---|---|
| [Writing for Success — Tara Horkoff и автор, имя которого удалено по просьбе издателя](https://opentextbc.ca/writingforsuccess/) | Абзацы, базовая грамматика письма, планирование и редактура; A2–C2 с поддержкой агента | CC BY-NC-SA 4.0, кроме отмеченных исключений |
| [Technical Writing Essentials — Suzan Last](https://opentextbc.ca/technicalwritingh5p/) | Аудитория, технические инструкции, отчёты, предложения; B1–C2 | CC BY 4.0 с исключениями для отдельных материалов; сохранять все уведомления |

Книги сохранены без изменений. Обложки и сторонние вставки могут иметь отдельные условия; лицензия всей книги не отменяет этих условий. Эта подборка предназначена для некоммерческого образования. Download for free from the B.C. Open Collection. Не переносите общую лицензию кода на эти PDF.

Это справочная библиотека, а не требование читать все книги подряд. Для уровня ниже A2 сначала используйте русские объяснения курса. Преподаватель выбирает одну релевантную главу, ученик применяет её на собственном примере. У H5P-версии интерактивные упражнения доступны на сайте; PDF содержит статическое представление.

## Murphy — приоритетный грамматический ресурс

См. [MURPHY.md](MURPHY.md). Полных коммерческих книг в публичной библиотеке нет. Личную легально полученную копию положите в `library/private/`, который исключён из Git. Учебные модули не зависят от покупки книги.

## Дополнительные источники по ссылкам

- [CEFR и описания уровней Совета Европы](https://www.coe.int/en/web/common-european-framework-reference-languages/level-descriptions): ориентиры навыков, а не готовый алгоритм определения уровня.
- [Cambridge Dictionary](https://dictionary.cambridge.org/): UK/US-аудио, IPA, примеры употребления; не копировать словарную базу целиком.
- [British Council LearnEnglish](https://learnenglish.britishcouncil.org/): внешняя практика чтения и живого аудирования; материалы не зеркалируются.
- [MDN: SpeechRecognition](https://developer.mozilla.org/en-US/docs/Web/API/SpeechRecognition): ограничения браузерного распознавания и обработки на сервере.
- [MDN Web Docs](https://developer.mozilla.org/en-US/docs/Learn_web_development): аутентичное техническое чтение для T-модулей, выбирать короткие фрагменты по текущему навыку.

Авторские задания курса написаны специально для проекта. Библиотечные книги используются как дополнительные источники; упражнения Murphy не перепечатаны. Свежесть технической документации проверяйте перед занятием: язык можно изучать и на старом тексте, но технические рекомендации могут устареть.

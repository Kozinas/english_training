# План создания и архитектура

Это исходный план. Текущие обязательные критерии — [REQUIREMENTS.md](REQUIREMENTS.md); реализованное и оставшееся — [IMPLEMENTATION.md](IMPLEMENTATION.md). Наличие маршрута из 40 топиков не означает полноту их наполнения.

1. Подготовить репозиторий и правила работы агента.
2. Создать независимый от диагностики маршрут Pre-A1 → C2 и техническую ветку.
3. Наполнить каждый интегрированный модуль теорией, контрастными примерами, упражнениями с ключами, чтением, отдельным аудиотекстом, письмом, речью, словарём и произношением.
4. Добавить общие справочники: времена, звуки, лексические темы, контрольные проекты; связать грамматику с Murphy и Hewings.
5. Добавить открытую библиотеку: PDF, происхождение, лицензия, дата получения, контрольная сумма. Коммерческие книги — официальные ссылки и локальная папка для личной копии.
6. Создать диагностику A1–C2 по грамматике, чтению и аудированию, затем письмо и речь с ручной рубрикой. Входной тест не является сертификацией.
7. Сделать веб-интерфейс без зависимостей: курс, тест, карточки, озвучивание, ASR, черновики, экспорт/импорт, предварительный план.
8. Проверить ключи, структуру, зависимости, планирование, сохранение, HTTP-доступ и ошибки. Документировать реальные ограничения.

Данные курса общие для браузера и Markdown. Сервер читает только публичные маршруты, личные данные остаются в браузере либо в ignored-каталоге. Уровень до ответов неизвестен. Сначала доступен весь курс; персональный маршрут появляется после диагностики.

Целевой полный курс охватывает основные системы языка от начального до продвинутого применения, без ложного обещания перечислить все слова, диалекты и исторические исключения. Число занятий и длительность топика не фиксируются; C1/C2 требуют объёмного чтения, аутентичного аудирования и общения. Материалы создаются независимо от результатов конкретного ученика, затем маршрут адаптируется по свидетельствам навыков.

## Объяснение

Third conditional: If + had V3, would have V3 — нереализованное прошлое. Mixed: If I had studied medicine, I would be a doctor now — прошлое условие, нынешний результат. Must have V3 — уверенный вывод о прошлом; might have V3 — возможность; can’t have V3 — невозможность по оценке говорящего. Should have V3 — ожидаемое/желательное прошлое действие; often regret. Wish + had V3 — сожаление о прошлом. Вывод остаётся выводом, не наблюдаемым фактом.

## Примеры: от простого к сложному

- We should have checked the address. — Надо было проверить адрес.
- If we had left earlier, we would have caught the train. — Если бы мы вышли раньше, успели бы на поезд.
- If the team had documented the decision, we would not be repeating the same debate now. — Если бы команда записала решение, мы бы сейчас не повторяли тот же спор.

## Чтение

The package arrived damaged, although the sender had wrapped it carefully. It might have been dropped during transport, but there is no evidence yet. If the courier had taken a photo at collection, the team could compare its condition. They should have requested one in advance.

## Речь и взаимодействие

С партнёром восстановите события по неполным данным. Разделяйте must have, might have и известные факты.

## Произношение

Should have в быстрой речи может звучать /ʃʊdəv/; на письме это have, никогда should of.

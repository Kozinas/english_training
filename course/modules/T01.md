## Объяснение

В инструкции называй действие и объект: Select the folder. Различай save (сохранить), submit (отправить форму), upload (загрузить на сервер), download (скачать с сервера). File — файл, folder/directory — папка/каталог. Сначала prerequisite, затем шаги, ожидаемый результат и восстановление после ошибки. Must, should, may могут выражать разную обязательность; читай определения конкретного документа.

## Примеры

- Select a folder and click Save. — Выбери папку и нажми Save.
- The field is required. — Поле обязательно.
- Before you submit the form, check that the selected environment is the one you intend to update. — До отправки формы проверь выбранное окружение.

## Чтение

To export your notes, open Settings and choose Export. Select a folder that you can write to. The application creates a JSON file containing your notes and tags. Exporting does not remove the original notes. To restore them on another device, use Import and choose the saved file.

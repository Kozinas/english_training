## Объяснение

Комментарий ревью: наблюдение → риск → предложение/вопрос. Различай обязательное исправление и предпочтение. Endpoint — точка API, payload — данные сообщения, response — ответ, assertion — проверяемое утверждение в тесте. Объясняй контракт через вход, выход, ошибки и побочные эффекты. Не утверждай безопасность или корректность только по прохождению теста: тест покрывает выбранные случаи.

## Примеры: от простого к сложному

- Could we handle the empty input explicitly? — Можем явно обработать пустой ввод?
- This test covers the success path only. — Тест покрывает только успешный сценарий.
- If the operation is retried after a timeout, can the same request create a second record, or is it idempotent? — Может ли повтор запроса после тайм-аута создать вторую запись, или операция идемпотентна?

## Чтение

A reviewer noticed that the handler returned success before the write completed. The author explained that this reduced response time. They agreed that the API contract required confirmed persistence, so the response would wait for the write. A separate test would cover a storage failure, rather than only the successful request.

Вопрос: Why was the response behaviour changed?

## Упражнения

1. The request ___ an error. (return, Present Simple)
2. Could we avoid ___ twice? (write)
3. ___ case (граничный)

## Словарь в контексте

- endpoint — точка API; an API endpoint
- payload — данные сообщения; validate a payload
- assertion — утверждение теста; a failed assertion
- edge case — граничный случай; handle an edge case
- idempotent — идемпотентный; an idempotent operation
- persistence — сохранение данных; confirmed persistence

## Письмо

Напиши 4 комментария ревью: bug, вопрос, рекомендация, похвала конкретного решения. У каждого должна быть понятная степень обязательности.

## Речь и взаимодействие

Автор и ревьюер обсуждают конфликт между скоростью и контрактом API. Договоритесь о проверяемом поведении.

## Произношение

Прочитай вслух HTTP status codes, null, boolean, array. Уточняй, читаешь ли acronym по буквам или как слово.

# T03 · B2 · Код-ревью, API и тестирование

Сгенерировано из data/*.mjs. Править источник, не этот файл.

Предпосылки: B203, B204, T02. Нет фиксированной длительности или числа занятий.

> Топик опубликован частично. Шкала учитывает только доступные подтемы; их 100% не означает завершение всего топика. Новые задания увеличат объём работы без потери прежних ответов.

Ещё не реализованы:

- Тестирование: предусловия, assertions, success/edge/error cases, покрытие, воспроизводимость и границы результатов.

После каждой подтемы обязателен отдельный тест. Открытые ответы ожидают содержательной проверки, а устная речь — прослушивания. Самопроверка не подтверждает отложенное освоение.

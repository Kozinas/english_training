# Контрольные проекты

Каждый проект использует новые задания, не повторяет ключи урока. Делите на 30-минутные сессии. Оценивайте по assessment/RUBRICS.md; контроль уровня требует нескольких свидетельств. Если не хватает речи или аудио, отметьте unknown и назначьте проверку.

| Этап | Письмо / чтение | Речь / слушание | Сложное продолжение |
|---|---|---|---|
| Pre-A1 | 5 фраз о себе, узнавание имени/времени/предмета | представиться, произнести имя по буквам, понять простую инструкцию | уточнить непонятое без перехода на русский |
| A1 | описание дня 80 слов, короткая записка | 1 минута о дне, договориться о времени | изменить план после нового условия |
| A2 | история/приглашение 100–120 слов | покупка/поездка/простая рабочая инструкция | объяснить причину и сравнить варианты |
| B1 | письмо о проблеме 150–180 слов, извлечение фактов из документа | связный рассказ 2 минуты и 3 вопроса | пересказать решение третьему человеку |
| B2 | рекомендация 220–280 слов с альтернативой | 4-минутный доклад и неподготовленный спор | новое ограничение бюджета/срока |
| C1 | синтез двух источников 350–500 слов | обсуждение 8 минут, смена регистра | объяснить противоречие и границу вывода |
| C2 | 1000–1500 слов, 3 источника, редактура и ограничения | доклад 8–10 минут, защита и медиация | смена аудитории и сильное неожиданное возражение |
| Technical | bug report → review → ADR → postmortem → RFC | stand-up, ревью, архитектура, интервью | изменение требований и точное обсуждение рисков |

Для каждого контроля агент сохраняет задание, сырой ответ, помощь, оценку по шкалам и следующий шаг. Через 7 дней дайте другую задачу с той же конструкцией. Через 2 недели пересмотрите план: удерживается ли навык, достаточно ли нагрузки, что мешает регулярности.

Примеры новых сложных условий: клиент не понимает термин; исходное предположение оказалось неверным; результат статистически неопределён; другой участник вкладывает в reliable иной смысл; нужно объяснить ограничение без защиты любой ценой. Оценивайте точность и понятность, а не количество редких слов.

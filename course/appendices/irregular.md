# Неправильные глаголы: основные формы и семейства

Сгенерировано из data/*.mjs; точка сборки приложений — data/reference.mjs.

Охват: широкий учебный справочник современного общего и технического употребления, включая британские/американские альтернативы и отдельно помеченные редкие литературные глаголы. Это не закрытый список всех исторических, диалектных форм и возможных производных. Производные семейства приведены отдельно; нельзя объявлять их числом независимых базовых моделей.

V1 используется после do/does/did, will, can: Did you write? V2 самостоятельно выражает Past Simple: I wrote. V3 используется после have для perfect и после be для passive: I have written; it was written. Само по себе I written неверно. После did не нужна вторая прошедшая форма.

Учить удобно через контрасты и свои фразы: put–put–put; keep–kept–kept; begin–began–begun; come–came–come. Сходное написание не гарантирует одинаковой модели: bring–brought, но sing–sang–sung. Особое внимание read и различиям lie/lay, rise/raise, hang/hanged.

Производные обычно наследуют модель основы: write → rewrite → wrote/rewrote → written/rewritten. Но нельзя переносить правило без проверки значения: cost «стоить» — cost, cost «рассчитывать стоимость» — costed. Альтернативы через / не всегда взаимозаменяемы: смотри примечания.

## Практика

1. Yesterday I ___ a short report. (write)
2. I have ___ a short report. (write)
3. Did she ___ the attachment? (send)
4. They have ___ three tests. (run)
5. The test ___ yesterday. (run; активный залог)
6. We ___ the same bug last week. (find)
7. The file was ___ by another process. (overwrite)
8. The service has ___ unavailable. (become)
9. I ___ on the sofa yesterday. (lie; лежать)
10. I ___ the book on the desk yesterday. (lay)
11. The price has ___ . (rise)
12. She ___ me how to test it. (teach; вчера)
13. I have never ___ this phrase. (hear)
14. They ___ a new team last year. (build)
15. Дай два допустимых причастия learn.
16. Почему read–read–read не означает одинаковое произношение?
17. Исправь We have went home.
18. Исправь Did you wrote this?
19. Напиши V2 и V3 для take, затем для retake.
20. Объясни hung и hanged.

<details><summary>Разбор после попытки</summary>

1. wrote — завершённое прошлое.
2. written — V3 после have.
3. send — базовая форма после did.
4. run — V3 совпадает с V1.
5. ran — V2.
6. found — V2.
7. overwritten — причастие после was.
8. become — V3.
9. lay — V2 непереходного lie.
10. laid — V2 переходного lay.
11. risen — V3; raise был бы переходным.
12. taught — V2.
13. heard — V3.
14. built — V2.
15. learnt / learned; региональные предпочтения не делают другой вариант ошибкой.
16. V1 /riːd/, V2/V3 /red/.
17. We have gone home. — V3 gone, не V2 went.
18. Did you write this? — did + V1.
19. took/taken; retook/retaken.
20. Hung о висении/подвешивании; hanged обычно о казни повешением.
